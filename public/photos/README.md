# Couple Photos Directory

Place your 8 photos in this folder with the following filenames:
- `photo1.jpg` (Cover & Memory 1 - Night kiss with hands over face)
- `photo2.jpg` (Memory 2 - Mirror selfie with off-shoulder top)
- `photo3.jpg` (Memory 3 - Car selfie with white plush toy)
- `photo4.jpg` (Memory 4 - Matching striped outfits outdoors)
- `photo5.jpg` (Memory 5 - Night outdoor cheek kiss)
- `photo6.jpg` (Memory 6 - Purple jersey & black shirt cafe selfie)
- `photo7.jpg` (Memory 7 - Striped shirt with hat & red shirt outdoors)
- `photo8.jpg` (Memory 8 - Warm cafe close-up selfie)

When you push this repository to GitHub and deploy to Vercel, Vite automatically bundles the files in `/public/` so they are served directly from your Vercel URL (e.g. `https://your-app.vercel.app/photos/photo1.jpg`).
